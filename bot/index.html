04FAQ

Questions, answered

How do I add OLIT to my server?

Click Add to Discord and choose a server. You need the Manage Server permission on that server.

How do I configure the bot?

Open the dashboard, log in with Discord and pick a server you manage. You can set custom commands, automod words, exempt users and a welcome channel. Changes apply without restarting the bot.

What data does OLIT store?

Discord user and server IDs, game statistics and leaderboard scores, your server configuration, and message content only while a command is in use. See the Privacy Policy.

Can I have my data deleted?

Yes. Ask in the support server and your data will be removed.

What does logging in to the dashboard give access to?

The dashboard asks Discord for read-only access to your profile and server list. The token stays in your browser's session storage and is never sent to OLIT's servers.
