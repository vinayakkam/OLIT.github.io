Everything in its place

Built on Arch Linux and KDE Plasma 6, with its own apps and widgets on top. No Microsoft or Apple logos, fonts, icons or wallpapers anywhere.

The Dusk launcher

A big clock, search that also does maths, folder shortcuts and recent files on the left; your favourite apps or all apps on the right. Press the Windows key.

Settings that do it all

Display, sound, Bluetooth, Wi-Fi and VPN, accounts and passwords, default apps, privacy, time and language: 31 pages, and you never leave the app.

Zero CPU at idle

Event-driven widgets, no watchdog timers, and only the services you use. An idle installed desktop measures 0.0% CPU and about 840 MB of RAM.

Setup, the installer

Language, disk, account, done. It installs on btrfs with snapshots, sets up the boot menu, and turns the firewall on. About 5 to 15 minutes.

Windows-style tools

Task Manager on Ctrl+Shift+Esc, Quick Settings on Win+A, the sign-out screen on Ctrl+Alt+Del, Settings on Win+I, Files on Win+E.

Dark, light and your colour

Twilight Dark and Twilight Light, with an accent colour that also recolours the icons. The boot menu, sign-in and lock screens match.

Download

The ISO is about 3 GB. GitHub limits files to 2 GB, so it comes in two parts that you join after downloading.

1. Download the ISO

Both parts, plus the checksum
Part 1 Part 2 Checksum

Save all three files in the same folder.

2. Join the parts

Run this in that folder

Windows

>cmd /c copy /b twilightos-*.iso.part1 + twilightos-*.iso.part2 twilightos.iso

Linux and macOS

$cat twilightos-*.iso.part1 twilightos-*.iso.part2 > twilightos.iso

Then check it: sha256sum twilightos.iso must match the checksum file.

3. Make a USB stick

8 GB or larger

Ventoy: copy the ISO onto the stick. Rufus: choose DD image mode when asked. Linux: sudo dd if=twilightos.iso of=/dev/sdX bs=4M status=progress oflag=sync.

Turn Secure Boot off in your PC's firmware settings, then start from the USB stick.

System requirements

64-bit PCs
Processor64-bit x86 (Intel or AMD)
Memory2 GB, 4 GB or more recommended
Disk20 GB to install, an SSD recommended
FirmwareUEFI with Secure Boot off (BIOS works too)

All files and release notes are on the GitHub releases page.

Try it, then install it

The USB stick starts a complete live desktop, so you can try everything before anything is changed on your PC.

Start from the USB stick

Pick “Start TwilightOS” in the boot menu. The desktop is ready in about a minute, with no password.

Double-click Install TwilightOS

Choose your language, the disk to use and your account. Setup uses the whole disk you pick, so back it up first.

Restart and sign in

Remove the USB stick, restart, and sign in with the password you chose. Updates come from Arch Linux through Discover.

Try TwilightOS

Start it from a USB stick and see if it feels like home. Nothing changes on your PC until you install.
