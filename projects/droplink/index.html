Send anything, to any of your devices

No accounts, no cloud storage, no size limit. The two devices talk to each other directly, and nothing in between ever sees your files.

Nearby devices, found for you

Devices on your network appear on the radar by themselves. Pick one and drop files, a whole folder, or your clipboard.

Across networks, too

Share a short room code or a droplink:// link and two devices on different networks connect directly over WebRTC.

Encrypted end to end

Every transfer is encrypted between the two devices. Both screens show the same short code, so you can check nobody is in the middle.

Nothing arrives uninvited

Incoming cargo waits for your OK. Trust a device once to let it send without asking. If the sender gives up, the offer closes at once.

Picks up where it stopped

A dropped link resumes instead of starting over, and every file is checked with SHA-256 when it lands, so what arrives is exactly what was sent.

Light on your machine

Files stream through in small chunks, the engine stays under 64 MiB of memory, and the animated pixel console pauses when you're not looking.

How it works

Install DropLink on both devices. That's the whole setup.

Find the other device

On the same network it shows up on the radar. Anywhere else, create a room and share its code.

Drop your cargo

Files, a folder or the text on your clipboard. Send to one device or several at once.

Accept and compare

The other side accepts, both screens show the same code, and the files land in its Downloads folder.

Windows

Windows 10 and 11, 64-bit
Installer (.exe)

Installs for you alone, with no administrator rights. Windows may say “Windows protected your PC” because the installer isn't code-signed yet. Choose More info → Run anyway.

CachyOS, Arch & Manjaro

pacman package
Download package
$sudo pacman -U droplink-bin-*-x86_64.pkg.tar.zst

Debian & Ubuntu

.deb package
Download .deb
$sudo apt install ./droplink-*-linux-amd64.deb

Fedora & openSUSE

.rpm package
Download .rpm
$sudo dnf install ./droplink-*-linux-amd64.rpm

Any Linux

AppImage, no install needed
Download AppImage
$chmod +x droplink-*-linux-amd64.AppImage && ./droplink-*-linux-amd64.AppImage

Install once, stay up to date

On Windows, DropLink checks for new versions and updates itself. Your settings, keys and trusted devices are kept.

A new version is out

DropLink checks when it starts and offers the new version with its release notes. Switch the check off in CONFIG → UPDATES.

Download & install

The installer is downloaded and its signature checked against DropLink's release key, so only official releases ever run.

Back in a few seconds

DropLink restarts on the new version. On Linux, install the new package the same way as the first one.
