Privacy Policy

Last updated: 26 June 2026

1. What we collect

  • Discord User IDs and Server (Guild) IDs
  • Game statistics and leaderboard scores
  • Server configuration (custom commands, automod settings)
  • Basic message content during active command usage only

2. How we use it

Data is used exclusively to provide bot functionality: tracking scores, delivering game experiences, enforcing automod rules, and maintaining per-server configuration.

3. Data sharing

We do not sell or share your data with third parties. Configuration data may be synced to a private GitHub repository owned by the OLIT developer.

4. Data retention & deletion

Data is retained as long as the bot is active in your server. To request deletion, contact us in the support server.

5. Dashboard OAuth

When you log in via Discord OAuth, we request read-only access to your profile and server list. Tokens are stored in session storage and never sent to our servers.
